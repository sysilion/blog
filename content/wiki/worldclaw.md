텍스트 프롬프트에서 탐색 가능한 대규모 3D 월드를 만드는, Tencent Hunyuan의 완전 에이전트 기반 [[coarse-to-fine]] 프레임워크. 논문 "WorldClaw: Agentic 3D Open-World Generation at Scale"(arXiv:2608.05248, 2026-08-05, Chunchao Guo 외).

## 무엇인가

새 생성 모델이 아니라 **오케스트레이션 설계**다. LLM 에이전트들이 이미지 생성 모델, 분할·복원 모델([[sam-3]]), 3D 생성 모델([[hunyuan3d]]), Blender([[blender-mcp]])를 도구로 부려, **전역 지형 + 인스턴스 단위로 편집 가능한 오브젝트** 로 구성된 씬을 만든다. 출력이 신경망 표현(NeRF·3DGS)이 아니라 텍스처 메시라서 게임 엔진에서 바로 편집·재사용할 수 있다는 점을 내세운다.

## 구조

| 단계 | 에이전트 | 입력 → 출력 |
| --- | --- | --- |
| 계획 | 의도 분석 · 씬 계획 | 프롬프트 → 구조화 씬 사양 P (지역·지형·오브젝트·재료·관계) |
| 전역 지형 | 지형 계획 · 지형 정제 | P → 시맨틱 레이아웃 맵 → 지역별 높이 필드 T + 재사용 프로토타입 산포 |
| 지역 오브젝트 | 지역 계획 · 씬 정제 | P, T → 디테일 지역만 2D 합성 → 인스턴스 분할·메시 복원 → 지형 위 배치 복구 |

- 단계 사이 인터페이스는 자유 텍스트가 아닌 **표준 스키마** 다. 테마·스타일 같은 전역 속성은 하위 필드에 상속된다.
- 정제 에이전트는 렌더 → 검사 → 국소 수정 루프를 돌며, "실질 문제 없음 또는 반복 예산 소진"에서 멈춘다.
- 기술적 기여의 중심은 지역 합성 이미지에서 복원한 오브젝트를 지형 위 3D 위치·스케일·회전으로 되돌리는 배치 복구와 접지율(contact ratio) 보정이다.

## 알아둘 것

- 2026-09 기준 **코드·가중치·라이선스 미공개.** GitHub 저장소(Tencent-Hunyuan/Hunyuan3D-WorldClaw)에는 README와 그림만 있다.
- 평가는 정성 비교만이다. 비교 대상은 [[worldgen]], Marble, SynCity, MajutsuCity, 코딩 에이전트 단독 실행.
- 저자가 밝힌 전제 부품은 Claude Opus 4.8, GPT-Image-2, SAM 3/SAM 3D, Hunyuan3D, Blender 5.1.1, H20 GPU 4장. 오픈소스 LLM·이미지 모델로는 지형 코드와 레이아웃 맵 품질이 부족했다고 적었다.
- 다음 방향으로 고정 메시 대신 **실행 가능한 코드로 표현되는 자산**(재료 노드 그래프, 파라메트릭 구조)과 Unreal 같은 게임 엔진 통합을 제시한다.
