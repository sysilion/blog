AWS·Azure·GCP 같은 클라우드 사업자에 할당된 IP 대역. ASN 단위로 공개돼 있어
가정용 회선(residential)과 쉽게 구분된다. 그래서 [[bot-detection|봇 탐지]]의 1차 신호로 쓰인다.

## 알아둘 것

**CI 러너는 전부 데이터센터 IP다.** GitHub Actions 러너는 Azure 대역을 쓴다.
그래서 로컬에서 200이 오던 요청이 CI에서만 403이 되는 일이 생긴다.
이때 [[user-agent]] 나 헤더를 브라우저와 똑같이 맞춰도 달라지지 않는다 — 헤더가 아니라 IP 문제다.

로컬 200 / CI 403 은 이 조건을 의심하라는 신호로 충분하다.
프록시 통로를 두었다면 **모든 요청 경로가 그 통로를 타는지** 확인해야 한다.
경로 하나만 빠져 있어도 그 경로만 깨진다.
