들여쓰기로 계층을 표현하는 데이터 직렬화 포맷. 설정 파일과 마크다운 frontmatter에 널리 쓰인다.

## 무엇인가

JSON의 상위집합이다. 같은 구조를 따옴표와 괄호 없이 쓸 수 있게 만든 것이 요점이고,
그 대가로 **값의 타입을 모양에서 추론한다.** 이 추론이 사고의 근원이다.

| 쓴 것 | 파싱 결과 |
| --- | --- |
| `x: 123` | number |
| `x: 2025-11-14` | **Date 객체** (YAML 1.1 timestamp) |
| `x: yes` / `x: no` | 구현에 따라 boolean (YAML 1.1) |
| `x: [a] b` | flow sequence 뒤 잉여 스칼라 → **파싱 에러** |
| `x: "2025-11-14"` | string |

### 두 가지 컬렉션 표기

- **block** — 줄바꿈과 들여쓰기로 쓴다. `- a` 를 줄마다.
- **flow** — JSON처럼 한 줄에 쓴다. `[a, b]`, `{k: v}`.

`[` 나 `{` 로 시작하는 값은 무조건 flow로 해석된다. 사람이 쓴 제목이
`[공지] 점검 안내` 처럼 대괄호로 시작하면 배열로 읽힌다. → [[yaml-frontmatter-bracket-title-breaks-parse]]

## 알아둘 것

- **의심스러우면 인용부호를 쓴다.** 특히 사람이 자유롭게 쓰는 필드(제목, 요약)는 항상 감싼다.
- 버전이 갈린다. YAML 1.1은 `yes`/`no`를 boolean으로, 1.2는 문자열로 본다.
  `js-yaml`, `yaml`, Go의 `gopkg.in/yaml.v3` 가 각기 다른 기본값을 쓴다.
- 탭 문자는 들여쓰기에 쓸 수 없다. 스페이스만.
- 파서를 라이브러리로 감쌀 때는 **에러에 파일 경로를 붙여 다시 던진다.** YAML 파서의
  스택 트레이스는 자기 내부만 가리키므로, 문서 수십 개를 처리하는 구조에서는 쓸모가 없다.
