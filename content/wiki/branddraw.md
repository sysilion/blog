네이버페이가 매일 **14:00** 에 여는 선착순 이벤트로, 참여자에게 브랜드 하나를 배정하고
그 브랜드에서 네이버페이로 결제하면 적립률을 얹어 준다.

## 무엇인가

- **배정받는 것은 적립률이다.** 뽑은 브랜드의 공식 결제처에서 실제로 결제해야 적립되고
  지급도 2~3일 뒤다. 결제하지 않으면 아무 일도 일어나지 않는다.
- 클릭만으로 즉시 들어오는 것은 당첨 화면의 **클릭포인트**(보통 10원) 하나뿐이다.
  커뮤니티에서 말하는 '브랜드뽑기 10원' 이 이것이다.
- 하루에 열리는 브랜드는 4개 안팎. 각 브랜드마다 선착순 물량이 있고 소진되면
  `soldOut` 이 된다.

## 구조

| 단계 | 화면 |
| --- | --- |
| 14:00 이전 | 카운트다운. 브랜드 목록은 그려지되 `.wait` 로 잠긴다 |
| 14:00:00 | 페이지가 스스로 `location.reload(true)` 하고 카드가 열린다 |
| 전 브랜드 마감 | `allSoldOut` — 화면이 **보너스 뽑기**(랜덤 배정)로 바뀐다 |

## 하루의 경계는 자정이 아니다

`eventStartDate` 는 항상 다음 14:00 이고, 당첨의 유효기간(`eventEndDate`)도 **익일 14:00**
이다. 즉 이 이벤트의 하루는 14시→14시다. 뽑은 브랜드에서 결제해야 하는 기한도 여기에 걸린다.

14시 이벤트가 끝난 뒤 목록 API 는 `openBrandList` 를 **빈 배열**로 돌려준다 (화면은
'쉬는 날'). 다음날 라인업이 서버에 채워지는 시각은 공개되지 않았다.

## 알아둘 것

- **선착순은 몇 분 만에 끝난다.** 정각을 놓치면 남는 건 보너스 뽑기뿐이라,
  '어느 브랜드를 고를지' 설정은 대개 평가조차 되지 않는다.
- 응모 API 에 `abusing` 응답 코드가 따로 있다. 요청을 직접 만들지 말고 창을 띄워
  카드를 눌러 페이지가 알아서 보내게 하는 편이 안전하다.
