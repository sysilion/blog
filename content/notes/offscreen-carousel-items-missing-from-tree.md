## 무슨 일이

이마트 앱 출석이 `'출석체크' 를 찾지 못함` 으로 실패했다. 지난주까지는 홈 아이콘 줄의
(964,1355)에 있던 아이콘이다.

## 원인

홈 아이콘 줄은 **2줄로 나오는 날과 1줄로 나오는 날이 있다.** 2줄이면 `출석체크` 가
오른쪽에 보이고, 1줄이면 `바로퀵` 오른쪽 화면 밖으로 밀려서 옆으로 넘겨야 보인다.

화면 밖 칸은 [[uiautomator]] 덤프에 **아예 나오지 않는다.** 좌표만 화면 밖으로 나온
노드가 있는 게 아니라 노드 자체가 없다.

```python
ns = A.nodes()
[(n.label, n.x) for n in ns if n.label and 1300 < n.y < 1400]
# [('오더픽', 115), ('오더투홈', 273), ('와인그랩', 430), ('디지털그랩', 588),
#  ('웰컴 체크인', 745), ('이마티콘', 903), ('바로퀵', 1037)]   ← '출석체크' 없음
A.find("출석체크")   # None
```

## 그래서

`SiteSpec.hscroll_anchor` 를 두었다. 진입 라벨을 못 찾으면 그 줄에 늘 있는 라벨(`오더픽`)의
높이에서 왼쪽으로 800ms 동안 넘기고 다시 찾는다. 한 번 넘기자 `출석체크` 가
(964,1355)에 나타났다.

이 단계를 "앱 안 다른 화면이니 뒤로" 보다 앞에 두어야 한다. 뒤에 두었을 때는 뒤로 →
종료 확인창 `취소` 를 두 번 반복하느라 107초가 걸렸고, 앞으로 옮기니 67초로 줄었다.

## 한 줄

트리에서 못 찾았다고 화면에 없는 것은 아니다. 가로로 넘기는 줄 같은 곳은 넘겨 봐야 트리에 나타난다.
