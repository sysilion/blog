## 무슨 일이

chicle 후원 통계에서 [[chzzk-hidden-donation-amount|금액 비공개]] 후원이 전체의 59%였다. 후원 직후의 채팅 반응(채팅 증가량, "ㄷㄷ" 같은 놀람 반응, 참여 인원)으로 금액을 유추해 보려고, 금액이 보이는 7개 채널의 후원 2,061건으로 먼저 검증했다.

## 원인

금액 자체가 거의 한 값이다. 공개 후원의 87%가 정확히 1,000원이고 1만원 이상은 2.7%, 5만원 이상은 1.1%다. 반응과 금액의 스피어만 상관은 모든 특징에서 ±0.15 안이었고, 참여 인원과 반응 수는 오히려 음의 상관이었다. 분위기가 달아오른 구간에 1,000원 후원이 몰리기 때문이다.

5만원 이상 22건만 반응이 달랐다 (후원 뒤 15초 채팅 증가량의 AUC 0.76). 그런데 그 기준으로 걸러도 걸린 것 중 5만원 이상은 4~5%뿐이다. 비공개 채널 1,157건에 적용하면 350건쯤이 고액으로 찍힌다. 실제 비율이 1%라면 합계가 수십 배 부풀어 오른다.

## 재현

후원 한 건의 반응 특징은 이렇게 뽑았다. `chats`는 분석용 채팅 레코드 목록이다.

```python
def lift(chats, t, after=15, before=120, gap=5):
    plain = [c for c in chats if not c.get("is_donation") and not c.get("event")]
    base = sum(1 for c in plain if t - before <= c["t"] <= t - gap) / (before - gap + 1)
    n_after = sum(1 for c in plain if t < c["t"] <= t + after)
    return n_after - after * base
```

공개 후원 2,061건을 `amount >= 50000`과 그 미만으로 나눠 `lift`의 AUC(Mann-Whitney)를 재면 0.76, `amount >= 10000` 기준이면 0.65가 나온다. 창을 30초·60초로 늘려도 같다. 채팅에 적힌 금액("10만원 ㄷㄷ")도 21건 중 1건만 실제 금액의 두 배 안에 들었다.

## 그래서

반응 모델은 넣지 않았다. 비공개 후원은 최소 후원액으로 채우고 ≈ 표시와 건수를 보여 주는 데서 멈췄다. 공개 채널의 한 건 기대값이 약 2,200원(상위 1% 제외 1,400원)이라, 합계를 더 맞추려면 채우는 금액을 그 값으로 두는 편이 반응 모델보다 낫다.
