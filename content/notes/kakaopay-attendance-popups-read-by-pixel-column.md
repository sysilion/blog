## 무슨 일이

카카오페이 출석을 adb 로 자동화하는데 `uiautomator dump` 가 버튼을 하나도 주지 않는다.
그래서 비율 좌표를 눌렀다. 오전과 오후의 좌표를 따로 뒀더니 날마다 팝업이 달라 빈 곳을 누르는 날이 생겼다.

## 원인

출석 화면은 노드 없이 통째로 그려지는 [[compose-canvas|캔버스]]다. 무엇이 떠 있는지 알려면 픽셀을 읽어야 한다.
`adb exec-out screencap` 의 raw 출력에서 x=0.2 세로줄 하나를 떼어, 같은 색이 이어지는 구간으로 나눴다.

| 팝업 | 세로줄에 보이는 띠 (높이 비율) |
| --- | --- |
| `N일차 오전 출석하기` | 파랑 `(26,150,255)` 0.692~0.739 |
| `아차! 연속 출석에 실패했어요` | 파랑 광고 버튼 0.611~0.658, 바로 아래 회색 `(37,40,43)` `1일차부터 다시 시작하기` |
| `오후 출석 완료하셨어요 — 두 가지 중 결정해주세요` | 파랑 없음. 흰색 `(229,233,237)` 0.537~0.655 = 왼쪽 카드 `출석만 하고 1P 받기` |

오후 팝업은 버튼이 아니라 카드 두 장이고, 뒤 화면은 흐리게 어두워진다.
세로줄이 왼쪽 카드를 지나니 흰 띠는 그 카드 하나뿐이다. 오른쪽 광고 카드는 이 줄에 안 걸린다.

## 재현

```bash
adb exec-out screencap > s.raw    # 앞 16바이트 헤더, 뒤 w*h*4 바이트가 RGBA
```

```python
import sys
w, h = 1080, 2640
raw = open("s.raw", "rb").read()[-w*h*4:]
x = int(w * 0.2)
col = [tuple(raw[(y*w + x)*4:(y*w + x)*4 + 3]) for y in range(h)]
# 이웃과 채널 차이가 8 이하인 픽셀을 묶어 구간으로 본다
```

## 그래서

파란 띠가 있으면 그것을, 연속 실패면 회색을 먼저, 파란 띠가 없고 흰 카드가 있으면 그 카드 가운데를 누른다.
누른 뒤 같은 높이의 띠가 사라졌으면 "완료" 로 적는다. → `naver/naverpay_click/appcheck.py` `_band_target`

## 한 줄

`uiautomator dump` 가 비어 있는 화면은 좌표를 고정하지 말고, 세로줄 하나를 색 구간으로 잘라 띠의 색과 높이로 팝업을 가린다.
