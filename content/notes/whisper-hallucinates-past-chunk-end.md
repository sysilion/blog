## 무슨 일이

chicle에서 VOD 20분 구간을 10분 조각 두 개로 나눠 [[whisper]](mlx-whisper, large-v3-turbo)로 전사했다.
첫 조각이 끝나는 지점에 같은 문장이 1초 간격으로 23번 찍혔다. 게다가 끝 시각이 시작 시각보다 앞섰다.

```
01:10:00,200 --> 01:10:00,000   남편면
01:10:02,200 --> 01:10:00,000   남편면
...  (01:10:23,200까지 23번)
```

## 원인

Whisper는 30초 창 단위로 디코딩하고, 마지막 창은 0으로 패딩한다. 패딩된 무음 구간에서
모델이 앞 문맥을 이어 붙여 짧은 문장을 반복 생성했고, 그 세그먼트의 시작 시각이 오디오 길이(600초)를 넘었다.
조각 끝으로 `end` 만 잘라 낸 탓에 `end < start` 가 됐다.

## 재현

```bash
cd chicle/backend
./venv/bin/python scripts/transcribe_vod.py 15756649 --start 3600 --end 4800 -o out.srt --chunk 600
grep -B1 '^남편면' out.srt | grep -- '-->'
```

## 그래서

조각 길이 이상에서 시작하는 세그먼트는 버리고, 남은 세그먼트의 `end` 는 조각 길이로 자른다.
경계 직전(598초)에도 `남 OS呓 전화án` 같은 깨진 문장이 하나 남았다. 이건 시각만으로는 걸러지지 않는다.

## 한 줄

Whisper 세그먼트를 쓰기 전에 시작 시각이 입력 길이 안에 있는지부터 거른다.
