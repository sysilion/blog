## 무슨 일이

이마트 앱 출석 자동화가 `이미완료 — 버튼이 '출석완료'` 를 보고했다. 스크린샷을 보니
오늘(28일) 칸은 비어 있었고, 아래 버튼도 여전히 `출석하기` 였다. 전날도 같은 이유로
빠진 것으로 보인다 — 27일 칸도 비어 있었다.

## 원인

판정은 "이 문구가 화면에 있으면 이미 했다" 는 **부분 일치**였다. 그런데 [[uiautomator]]
트리에서 달력의 지난 칸이 전부 이런 노드로 나온다.

```
Node('1일차 출석완료' @397,1840)
Node('2일차 출석완료' @539,1840)
...
Node('26일차 출석완료' @959,2326)
Node('출석하기' @540,2565)          ← 오늘은 아직
```

`출석완료` 는 첫 번째 칸에서 바로 걸린다. 성공 문구와 '이미 했다' 문구를 같은 말로
두면, 달력이 있는 화면에서는 한 번이라도 출석한 달이면 늘 '이미완료' 가 된다.

## 재현

```bash
adb shell uiautomator dump /sdcard/w.xml
adb shell cat /sdcard/w.xml | grep -o 'text="[^"]*출석완료"' | head -3
# text="1일차 출석완료"
# text="2일차 출석완료"
```

## 그래서

판정 문구에 **오늘 날짜**를 넣었다 — `{day}일차 출석완료` 를 실행 시 `28일차 출석완료` 로
채운다. 고친 뒤 같은 화면에서 `출석하기` 를 눌렀고 'e머니 10점 · 오늘 출석 완료!' 가 떴다.

한 줄: 달력이 있는 화면에서 '완료' 는 과거형이다. 오늘 칸을 가리키는 문구로만 판정한다.
