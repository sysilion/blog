게임 설계 문서에 "접근 불가 셀의 `H = 0`(피난처 하한)이 절멸을 구조적으로 차단한다"는 불변식이 있었다.
근거는 Huffaker 1958 — 지속은 개체 능력이 아니라 공간 구조에서 나온다는 것.
[[logistic-growth|로지스틱 성장]] + 4-이웃 분산 격자를 구현해 확인해 보니, 그 문장은 조건부였다.

## 무슨 일이

24×16 격자, 종 3개, 접근 가능한 모든 셀을 매 틱 수확하는 최대 압력으로 100일(1,200틱)을 돌렸다.

| 종 | 성장률 `r` | 분산률 `m` | 피난처 있음 | 피난처 0% | 남은 것 중 피난처 안 |
|---|---:|---:|---:|---:|---:|
| 약초 | 0.18 | 0.08 | 0.287 | 0.026 | 38% |
| 광석 | 0.02 | 0.00 | 0.153 | 0.008 | 95% |
| 사냥감 | 0.10 | 0.05 | 0.118 | 0.000 | 60% |

(값은 `Σd / ΣK`. 1.0이면 수용력만큼 차 있다는 뜻)

절멸(`Σd = 0`)은 확실히 막힌다. 그런데 **분산률이 0인 광석은 남은 것의 95%가 피난처 안에 갇혀 있다.**
바깥은 사실상 비었다. 피난처가 보호구역이 아니라 금고가 된 것이다.

## 원인

분산 항이 피난처와 바깥을 잇는 유일한 통로다.

```text
d' = d + r·d·(1 − d/K) − H + m·Σ(d_이웃 − d)
```

`m = 0`이면 피난처 밖으로 한 마리도 나가지 않는다. 피난처 안은 `K`까지 차고 거기서 멈춘다.
`m > 0`이면 피난처가 소스가 되어 빈 셀로 흘러나가고, 빈 셀은 `1 − d/K`가 크므로 성장이 빠르다 —
[[source-sink-dynamics|소스-싱크]] 구조다.

그래서 **분산률에 최적값이 생긴다.** 약초의 `m`만 바꿔 60일을 돌리면:

```text
m = 0    → 0.193
m = 0.02 → 0.278
m = 0.05 → 0.290   ← 최대
m = 0.08 → 0.287
m = 0.12 → 0.278
m = 0.2  → 0.257
```

`m`이 과하면 흘러나온 만큼 바로 걷혀 도로 줄어든다.

그리고 **회복률에 임계가 있다.** 약초의 `r`만 바꾸면:

```text
r = 0.02 → 피난처 있음 0.000 / 없음 0.000
r = 0.05 → 0.000 / 0.000
r = 0.10 → 0.071 / 0.000
r = 0.18 → 0.287 / 0.026
```

`r`이 낮으면 피난처가 있으나 없으나 바깥은 죽는다. 피난처가 열 배 이상의 차이를 만드는 건 `r`이 충분할 때뿐이다.

## 재현

```bash
cd prototypes/harvest-topdown-game
npm install
npx vitest run tests/extinction.test.ts
```

`maxPressure(profile, days)`가 위 표를 만든다. 종별 `r`·`m`만 바꾼 변형 비교도 같은 파일에 있다.

## 그래서

Huffaker의 실험에서 지속을 만든 것도 피난처의 존재가 아니라 **분산에 걸린 지연**이었다.
"접근 불가 셀을 두면 안전하다"는 한 줄짜리 불변식은, 그 셀에서 바깥으로 나가는 속도와
나간 개체가 번식하는 속도를 같이 적지 않으면 절반만 참이다.

피난처 하한은 절멸을 막는다. 붕괴는 막지 않는다.
